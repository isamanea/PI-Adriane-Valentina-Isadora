# PI-Adriane-Valentina-Isadora
# Empowerher - Adriane Carlotto, Valentina Machado e Isadora Manéa

Ajudando mulheres em situação de vulnerabilidade.

---

## Stack

| Tecnologia | Uso |
|------------|-----|
| **Next.js 16** (App Router) | Framework React com API Routes |
| **Tailwind CSS 4** | Estilização (tema dark, estética terminal/cybersecurity) |
| **Lucide React** | Ícones |
| **TypeScript** | Tipagem |

---

## Quick start

```bash
# Instalar dependências
npm install

# Desenvolvimento (http://localhost:3000)
npm run dev

# Build de produção
npm run build

# Rodar em produção
npm run start
```

A raiz `/` redireciona para `/hashes`. Navegue pelo menu lateral para acessar cada módulo.

---

## Módulos

| Rota | Módulo | Descrição |
|------|--------|-----------|
| `/cadastro` | Cadastro de Usuária |Cadastro seguro para acesso aos recursos da plataforma. |
| `/ajuda` | 	Central de Ajuda | Orientações e informações para mulheres que estejam enfrentando situações de vulnerabilidade ou violência. |
| `/login` | Autenticação | Controle de acesso à plataforma por meio de login e senha. |
| `/contatos` | Rede de apoio | 	Lista de serviços e contatos de órgãos e instituições que podem oferecer suporte e proteção. |
